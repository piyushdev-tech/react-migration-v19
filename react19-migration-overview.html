The complete migration path · Bethos standards

Eleven gated phases, from evidence to delivery

Each phase must be green before the next begins. Planning inspects; implementation changes and proves.

Stage 1 · plan / read-only

0Baseline
Choose scope, branch, and prove React 18 tests/build pass.
1Peer matrix
Check every dependency against live React 19 support.
2TypeScript check
Confirm the installed TypeScript can use React 19 types.
3Security + stability
Record audit results and choose stable, minimal target versions.

Stage 2 · implement / verify

4API Compatibility Fixes
Find outdated React patterns and manually apply their React 19 replacements.
5TypeScript fixes
Fix refs, JSX namespace, and reducer typing changes.
6Dependencies + React
Upgrade flagged packages, then bump React to 19.2.8.
7Component loop
Run each component test; fix only what fails.
8Logic freeze
Review the diff and confirm changes are mechanical only.
9Full verification
Run tests, build, lint, manual QA, and an audit re-check.
10Deliverable
Finalize the playbook and migration checkpoint for handoff.
